# `gno.land/r/moul/home`

moul's personal dashboard realm: a meme, a status line, and a todo list,
rendered as the page at `/r/moul/home`.

```go
func Render(path string) string
func AddNewTodo(cur realm, todo string)
func DeleteTodo(cur realm, todoIndex int)
func UpdateStatus(cur realm, newStatus string)
```

Every mutator calls `assertIsAdmin()` first, which compares
`unsafe.PreviousRealm().Address()` against a hardcoded constant
(`g1manfred47kzduec920z88wfr64ylksmdcedlf5`). There is no transfer of
ownership: the admin is a `const` in the source, so changing it means
redeploying.

`Render` ignores its path and always returns the whole dashboard.

## Why the path has no `/vN`

Every other contract in this repo is versioned. This one cannot be. gnoweb
builds a user's profile page by calling `Render("")` on the realm at exactly
`/r/<username>/home`, with no version resolution, so `home/v0` would never be
found. The bare path is the interface.
