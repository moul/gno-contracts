ASCII and pixel art on gno.land, rendered rather than described:
[**the gallery**](/r/moul/gallery/v0).

It stores nothing. Every piece lives where its author put it, and the gallery
renders the ones it can import and points at the ones it cannot. Settler #25 is
there, and the generators: gnoface, millipede, sapin.

Every page also answers to `?fmt=txt`, which is the same document built for a
terminal instead of a browser: no markdown syntax, links as numbered footnotes,
columns that line up. Try
[the index as plain text](/r/moul/gallery/v0:?fmt=txt).
