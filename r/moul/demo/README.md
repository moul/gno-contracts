# `r/moul/demo` — examples & educational content

This folder holds gno contracts I keep around as **examples** — code I like to be
able to point at to show a pattern or a snippet, **not** packages I expect to
actually deploy or use in production.

Treat everything here as **educational / reference material**:

- It demonstrates an idea, an API shape, or a technique.
- It is versioned and CI-tested against gno master like the rest of the repo, so
  the examples stay compilable — but longevity, completeness, and real-world
  fitness are explicitly **not** goals.
- Prefer the non-`demo` packages in this repo for anything you intend to build on.

[DISCLAIMER](../../../DISCLAIMER.md) for the full catalog and terms.
