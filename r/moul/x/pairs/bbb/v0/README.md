# `gno.land/r/moul/x/pairs/bbb/v0`

A throwaway GRC20 (BBB, 6 decimals) with an **open faucet**, used to exercise
the pair instances in this repo. No value, no owner controls, anyone can mint.

`Faucet` mints 1000 BBB to the caller. Registered in `r/nt/grc20reg/v0` at
deploy, so its key is `gno.land/r/moul/x/pairs/bbb/v0.BBB`, which is what an
instance realm is configured with.
