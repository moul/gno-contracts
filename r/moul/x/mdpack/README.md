# MDPack

A small realm demonstrating the packed-file Markdown syntax from
[gnolang/gno#4496](https://github.com/gnolang/gno/pull/4496). It contains a
one-pixel PNG and a JSON object.

Open the realm for the original pack fences. The `:pixel.png` and `:data.json`
subpages show the payloads as copyable text. Serving those payloads as media
or downloads would require support in the Markdown renderer.
