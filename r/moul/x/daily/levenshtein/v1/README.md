# levenshtein

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Go→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

---


An on-chain port of the classic **Levenshtein edit-distance** algorithm — the same
idea behind Go libraries like [`agext/levenshtein`](https://github.com/agext/levenshtein).
It computes the minimum number of single-character insertions, deletions, or
substitutions needed to turn one string into another, using the textbook
dynamic-programming matrix, fully rune-aware and deterministic (no clocks, I/O, or
randomness), so it runs as a pure gno.land realm.

## API

- `Distance(a, b string) int` — the edit distance.
- `Matrix(a, b string) [][]int` — the full DP matrix (bottom-right = distance).
- `Similarity(a, b string) int` — a 0..100 similarity percentage.

## Render paths

- `Render("")` — explanation + linked examples, including `kitten → sitting = 3`.
- `Render("/kitten/sitting")` — the two words, their edit distance, similarity, and the DP table.
- `Render("/café/cafe")` — rune-aware: distance `1`, not several bytes.
