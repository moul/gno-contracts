# ROT13

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Go→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

An on-chain port of Go's classic **ROT13** cipher — the canonical
`strings.Map` / `io.Reader` example from the standard-library documentation.
Each ASCII letter is rotated 13 places through the alphabet (non-letters pass
through untouched), so because 13 is exactly half of 26, **ROT13 is its own
inverse**. The realm also exposes a general **Caesar** shift, of which ROT13 is
just the shift-13 case. All logic is pure `strings`/`unicode` — no state, no
randomness, no clock.

Realm: `gno.land/r/moul/x/daily/rot13/v1`

## Exported functions

```go
Rot13(s string) string          // ROT13; self-inverse
Caesar(s string, shift int) string // general shift, normalized to [0,26)
```

## Render paths

```
Render("")                         // overview + worked example (self-inverse demo)
Render("/Hello, Gno!")             // shows input and its ROT13 -> "Uryyb, Tab!"
Render("/Uryyb, Tab!")             // decodes back to "Hello, Gno!"
Render("/caesar/3/attack at dawn") // Caesar shift of 3
```

Paths accept `%20`/`+` escapes for spaces and punctuation.
