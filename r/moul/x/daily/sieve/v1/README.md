# Sieve of Eratosthenes

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Go→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

---


A gno.land realm port of Go's famous **concurrent prime sieve** example (the
goroutine/channel `Sieve` from the Go tour and Go source docs). On-chain code
must be deterministic, so this keeps the *spirit* — a streaming sieve of
primes — but implements the classic **Sieve of Eratosthenes** sequentially and
reproducibly (no goroutines or channels). `n` is capped at `10000` to bound gas.

## API

- `PrimesUpTo(n int) []int` — every prime ≤ `n` (clamped to `[0, 10000]`).
- `NthPrime(k int) int` — the k-th prime (1-indexed), `0` if beyond the cap.
- `IsPrime(x int) bool` — trial-division primality test.

## Render paths

- `Render("")` / `Render("/")` — the first 100 primes as a grid plus the total
  count of primes up to the cap.
- `Render("/500")`, `Render("/1000")`, … — every prime ≤ n laid out as a grid.
