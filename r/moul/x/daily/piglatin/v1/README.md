# Pig Latin

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Go→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

---


An on-chain port of the classic **Pig Latin** translator — the quintessential
Go beginner exercise — reimplemented as a gno.land realm. It applies the standard
English rules (vowel-start → `+way`; consonant cluster moved to the end `+ay`;
`y` as consonant only in first position) while preserving capitalization and
punctuation. Everything is pure `strings`/`unicode`, so it's fully deterministic
on-chain.

## Usage

- `Translate(sentence string) string` — translate a whole sentence, preserving
  spacing (`Translate("Hello, world!")` → `"Ellohay, orldway!"`).
- `Render("/")` — explains the rules with examples.
- `Render("/<sentence>")` — shows the original and its Pig Latin, e.g.
  `Render("/The quick brown fox")`.

## Examples

| Input | Pig Latin |
|---|---|
| `pig` | `igpay` |
| `string` | `ingstray` |
| `apple` | `appleway` |
| `yellow` | `ellowyay` |
| `Hello,` | `Ellohay,` |
