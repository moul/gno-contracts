# `gno.land/r/moul/x/daily/levenshteindemo/v1`

Interactive gnoweb **demo of the [`p/moul/x/daily/levenshtein`](https://github.com/moul/gno-contracts/tree/main/p/moul/x/daily/levenshtein/v1)
edit-distance library** — it renders an explanation, worked examples, and a
distance calculator with the full dynamic-programming table. It has no distance
logic of its own.

Append two words as `/<a>/<b>` to compute their distance, e.g.
[`/r/moul/x/daily/levenshteindemo/v1:kitten/sitting`](https://gno.land/r/moul/x/daily/levenshteindemo/v1:kitten/sitting).
