# `gno.land/r/moul/x/daily/piglatindemo/v1`

Interactive gnoweb **demo of the [`p/moul/x/daily/piglatin`](https://github.com/moul/gno-contracts/tree/main/p/moul/x/daily/piglatin/v1)
Pig Latin library** — it renders the rules, a gallery of worked examples, and a
live sentence translator. It has no translation logic of its own.

Append a sentence to the path to translate it, e.g.
[`/r/moul/x/daily/piglatindemo/v1:/The quick brown fox`](https://gno.land/r/moul/x/daily/piglatindemo/v1:/The%20quick%20brown%20fox).
