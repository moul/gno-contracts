# Markov Babbler

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Go→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

---


An on-chain port of Go's canonical example **"Generating arbitrary text: a
Markov chain algorithm"** ([go.dev codewalk](https://go.dev/doc/codewalk/markov/)).
It keeps the original's core — a map from each two-word *prefix* to the list of
words that followed it, then a random walk that babbles new text — but stores
the corpus in a persistent `avl.Tree` and swaps `math/rand` for a small LCG
seeded by `runtime.ChainHeight()`, so `Generate` stays pure and reproducible
while still varying block to block.

`Feed(cur, text)` tokenizes text and folds it into the chain (extending one
continuous corpus across calls); `Generate(nWords)` walks the chain from the
start prefix. The realm ships pre-seeded with a couple of sentences, so a fresh
deploy already babbles.

## Example calls / Render paths

- `Feed("the quick brown fox jumps over the lazy dog")` — grow the corpus.
- `Generate(40)` — babble ~40 words, seeded by the current block height.
- `Stats()` — returns `(totalWords, prefixCount)`.
- `Render("/60")` — a fresh 60-word sample plus corpus stats and a sample of
  prefix → suffix rows. `Render("")` defaults to 40 words.
