# semver

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Go→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

---


An on-chain port of the core of Go's [`golang.org/x/mod/semver`](https://pkg.go.dev/golang.org/x/mod/semver)
(and the spirit of [`Masterminds/semver`](https://github.com/Masterminds/semver)).
It parses `vMAJOR.MINOR.PATCH[-prerelease][+build]` strings and compares two
versions with correct Semantic Versioning 2.0.0 precedence: numeric fields
compare numerically (so `1.2.3 < 1.2.10`), a pre-release ranks below its release
(`1.0.0-alpha < 1.0.0`), numeric pre-release identifiers rank below alphanumeric
ones, and build metadata is ignored. Everything is pure and deterministic.

## API

- `Parse(s string) (Version, error)` — parse a version string.
- `Compare(a, b string) int` — returns `-1`, `0`, or `+1`.
- `Submit(cur realm, version string)` — store a valid version on-chain, tagged
  with the caller, for the sorted listing.

## Render paths

- `/` — overview plus a table of worked examples.
- `/<a>/<b>` — parse both versions and show the comparison, e.g.
  `/1.2.3/1.2.10` or `/1.0.0-alpha/1.0.0`.
- `/sorted` — everyone's submitted versions, lowest → highest precedence.
