# romannum

An on-chain Gno port of the classic **Roman numeral converter** kata. It reimplements
the two canonical functions — `ToRoman(n int) string` (greedy subtractive notation,
valid for 1..3999, panics out of range) and `FromRoman(s string) int` — as a pure,
deterministic realm. `FromRoman` accepts a numeral only if it is canonical (it must
round-trip through `ToRoman`), so malformed forms like `IIII`, `VV`, or `IC` are rejected.

## Render paths

- `:` / root — a table of example conversions (1, 4, 9, 40, 90, 400, 900, 2024, 3999, …).
- `:/<n>` — integer → Roman, e.g. `:/2024` → `MMXXIV`.
- `:/r/<roman>` — Roman → integer, e.g. `:/r/MMXXIV` → `2024` (case-insensitive).
