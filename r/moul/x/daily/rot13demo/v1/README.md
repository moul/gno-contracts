# `gno.land/r/moul/x/daily/rot13demo/v1`

Interactive gnoweb **demo of the [`p/moul/x/daily/rot13`](https://github.com/moul/gno-contracts/tree/main/p/moul/x/daily/rot13/v1)
ROT13 / Caesar library** — it renders an explanation, a worked ROT13 example,
and path-driven ROT13 and Caesar transforms. It has no cipher logic of its own.

Append text to the path to ROT13 it, e.g.
[`/r/moul/x/daily/rot13demo/v1:Uryyb, Tab!`](https://gno.land/r/moul/x/daily/rot13demo/v1:Uryyb,%20Tab!),
or use `/caesar/<shift>/<text>` for a general Caesar shift.
