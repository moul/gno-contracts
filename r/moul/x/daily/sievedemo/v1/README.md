# `gno.land/r/moul/x/daily/sievedemo/v1`

Interactive gnoweb **demo of the [`p/moul/x/daily/sieve`](https://github.com/moul/gno-contracts/tree/main/p/moul/x/daily/sieve/v1)
Sieve of Eratosthenes library** — it renders the count of primes up to `MaxN`,
the first 100 primes, and a "primes up to n" grid. It has no sieve logic of its own.

Append a number to the path to sieve up to any n (max 10000), e.g.
[`/r/moul/x/daily/sievedemo/v1:1000`](https://gno.land/r/moul/x/daily/sievedemo/v1:1000).
