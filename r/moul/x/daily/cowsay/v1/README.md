# cowsay

An on-chain Gno port of the classic **cowsay** program (Tony Monroe, 1999) — the
Unix toy that draws an ASCII cow saying whatever you tell it. This realm
reimplements the core: word-wrapping the message into a speech balloon (single
line uses `< >`, multi-line uses `/ \ | |` borders) and stacking the happy cow
underneath, all as pure deterministic string art rendered in a Markdown code
block so gnoweb shows it monospaced.

## Usage

- `Render("")` — shows the default message (`Moo!`).
- `Render("/Hello, gno.land!")` — the cow says "Hello, gno.land!".
- `Render("/the quick brown fox jumps over the lazy dog")` — long text is
  word-wrapped into a multi-line balloon.
- `Say(msg string) string` — helper returning the raw art (bubble + cow).

## Example

`Render("/Moo!")`:

```
 ______
< Moo! >
 ------
        \   ^__^
         \  (oo)\_______
            (__)\       )\/\
                ||----w |
                ||     ||
```
