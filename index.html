The previews moved

gno-contracts previews are now published to moul.github.io/gno-contracts-previews: main/ for the default branch, pr-<N>/ per pull request.

They were served from this branch until 2026-09-21. It was moved out because a full snapshot of the repository is ~100 MB rewritten on every push, and this branch is one that every git clone of gno-contracts downloads. The old pr-<N>/ snapshots are gone; they were all for closed pull requests.
